## 📌 Descripción del Proyecto
Sistema orientado a la gestión integral de una empresa de confecciones. Cubre el control de clientes, catálogo de productos, registro de materias primas, seguimiento de pedidos, facturación y control de inventario básico.

---

## 🛠️ Tecnologías Utilizadas
* **Lenguaje:** Java
* **Base de Datos:** MySQL
* **IDE:** Apache NetBeans
